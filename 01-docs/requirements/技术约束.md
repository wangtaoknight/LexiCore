### 技术栈及开发约束

采用以下技术栈：

- Node.js + TypeScript
- React + Vite
- Express
- SQLite + better-sqlite3
- AI API 通过 Node.js 后端调用

所有代码集中在一个项目中，不采用微服务架构。

开发原则：

1. 优先采用成熟、简单的依赖，不要为了实现简单功能引入大型框架。
2. 不要引入不必要的状态管理工具。
3. 不要引入复杂的数据库 ORM，优先使用清晰的 SQL 和参数化查询。
4. 数据库使用本地单文件 SQLite。
5. AI API Key 只能保存在后端环境变量或本地安全配置中。
6. AI 返回数据必须进行结构化校验，不能直接把未经校验的 JSON 写入数据库。
7. 所有数据库变更采用版本化迁移。
8. 所有审核记录必须持久化保存。
9. 必须实现数据库备份和恢复。
10. 前端、后端、数据库访问、AI 调用分别保持清晰的模块边界。
11. 不要过度设计，不要为了未来可能出现的需求提前增加复杂架构。
12. 每次只实现一个完整功能模块，并进行测试后再继续。

软件首先以本地单用户应用运行，不需要登录系统、云数据库和公网部署。
