## [Unreleased]

### Changed

- **审核工具统一收进「点击模块标题」的弹窗**：① 英文释义 / ② 中文释义 / ③ 典型例句 / ④ 固定搭配 / ⑤ 同(反)义词 的标题都可点击，弹窗提供**取消 / 全部驳回 / 全部通过**三个选项（含可选的驳回意见）；①② 是单条内容，弹窗里同时保留「重新分析 / 修改 / 追问 / 历史」等单条操作。
- 模块内不再有常驻操作条：例句/固定搭配只在鼠标所在的**那一行**显示操作条，左栏「词源与词义脉络」悬浮才显示；隐藏时不占位。
- 义项头部改为一行：中文译法 + 词性 + 词性细节标签 + 词频，之间留出间隔。
- 典型例句、固定搭配的「展开全部 X 条 / 折叠全部 X 条」移到**模块标题右侧**（不再在底部）；英文释义的「翻译」按钮也移到标题右侧（与标题隔约 4 个空格）。
- 义项研究栏内的所有折叠按钮（义项标签开关、中文释义细节、例句译文、同(反)义词解释）**只保留小箭头，不再有边框与底色**。
- 典型例句、固定搭配改为**单栏一行一条**，默认只显示 4 条：≤4 条时全部显示且不再显示「共 X 条」；>4 条时底部出现**展开全部 X 条 / 折叠全部 X 条**。
- 同(反)义词的「同 / 反」两组并排在一行，装不下才换行。
- 同(反)义词的词在行内并列（`同 series ^ set ^ array ^ | 反 individual ^`），每个词的对比解释默认折叠，`^` 展开后在词后单独占一行。
- 英文释义句末自动补英文句号（仅展示层），「翻译」按钮改为紧跟在句子后面。
- 典型例句：句末新增 `^` 按钮折叠/展开该句中文译文（默认隐藏）；来源标签紧跟在句末，有链接时点击跳转。
- 新增模块 ⑤ 同(反)义词：同义词 / 反义词分组展示；无反义词时标题为「同义词」，可在反义词位置上让 AI 针对当前义项补充反义词候选（新接口 `POST /api/items/:id/antonyms`，结果待审核）。
- **义项研究栏模块化精简**：右侧改为「当前义项头 + 内容模块」——① 英文释义（可按需翻译）② 中文释义（细节可折叠）③ 典型例句（按句长排序，默认 3 条）④ 固定搭配（只保留搭配 + 一条例句）。
- 义项切换标签默认隐藏，标题旁新增 `^` 按钮按需展开（左侧「当代词义地图」已可切换义项）。
- 义项头补全词性细节：新增可选字段 `posTags`（及物/不及物、可数性、语域或学科标签），旧记录显示「词性细节待补充」。
- 新增 `POST /api/items/:id/translate`：按需翻译英文释义，结果不写库。
- 例句/搭配的单条仍保留重新分析、修改、追问、历史版本、解除通过。
- 词义历史、近义词、反义词不再出现在详情页（数据与审核中心保持不变）。
- 单词详情页左栏「当代词义地图」去掉标题与义项计数（信息冗余）；义项默认只展示 3 条，超过 3 条时左侧出现一条**可点击的大箭头栏**用于展开/收起，避免义项过多把下面的词义脉络挤走。
- 「词源与词义脉络」改为默认展开。
- 单词详情页左栏重构为三段：**单词基本信息 → 当代词义地图 → 词源与词义脉络（折叠）**。
  - 「当代词义地图」直接复用已有义项数据（编号 + 中文译法 + 词性），点击可在右侧打开对应义项，不生成任何新内容；没有义项时显示空状态。
  - 「词源与词义脉络」把原有的「词源」「语义演变」合并为可折叠区域，默认收起。
  - 「核心意义」「核心意义说明」不再出现在主视图（**字段与历史数据保留，不做迁移**）。
- 「生成单词概览」的提示词不再要求输出 `coreMeaning` / `coreMeaningNote`（已停用）。
- 项目更名为「词穹 Lexicosmos · 单词的星空」：顶栏品牌、浏览器标题、`package.json` 包名同步更新。
- 单词详情页右栏上移：标题行去掉多余的 26px 上间距，整页再上移 20px 贴近顶部栏，义项面板可用高度更大。
- 单词详情页的审核状态改为按**义项**计进度：全部完成显示「已审核」，否则显示「待审核 完成数/义项总数」（义项及其全部子条目都通过才算完成）。
- 单词详情页的义项编号改为按常见程度重编（1..N），与筛选器顺序一致。
- 仓库结构调整为分层目录：`00-inbox/`（原始资料）、`01-docs/`（项目文档）、`02-code/`（可运行代码）、`04-data/`（静态数据）、`07-archive/`（归档）。见 [ADR-006](adr/ADR-006-repo-layout.md)。
- 待研究词表的导入路径改为可配置项 `VOCABULARY_IMPORT_FILE`，默认指向 `04-data/fixtures/vocabulary copy.txt`。

## [0.1.0] - 2026-11-15

### Added

- 单词 → 义项两级生成：`word_overview`（基本信息 + 义项清单）与 `sense_study`（概念解释、词义历史、例句、搭配、近反义词）。
- 通用内容单元模型：8 种 `kind` 全部可独立审核。
- 审核状态机：通过 / 驳回（附意见）/ 修改 / 重新分析 / 追问 / 解除通过，`approved` 内容受保护。
- 版本历史：AI 原稿固定为 v1，任何修改都生成新版本，支持并排差异对比。
- 审核中心：跨单词按状态与类型集中处理待办。
- 导出（JSON / Markdown，可按「仅已通过」）、数据库备份与恢复（`VACUUM INTO` 一致快照）。
- 例句联网核实：DeepSeek Search & Fetch + 本地逐字比对，未匹配到原文的例句不写入。
- 设置页：Base URL / API Key / 模型 / temperature / max_tokens / thinking 开关，API Key 加密存储。
- 测试：Vitest，覆盖工具函数、API 全流程（mock 模式）、网络错误翻译、模糊匹配，共 34 项。

### Fixed

- 长文本生成在非流式等待期间被中间设备重置（`CONNRESET`）→ 改用 SSE 流式。
- `better-sqlite3` 在无 Python / MSVC 环境下编译失败 → `npm install --ignore-scripts` + 预编译包脚本。
- 迁移器与 `schema_migrations` 建表语句冲突。
- 单词输入的大小写、空格、引号/破折号差异导致的重复词条。
